# v0.7.1 — 手机连接与传文件更顺畅

## 优化

[1] 优化了手机端发出无效请求的问题。手机停止轮询由电脑处理的配对审批，电脑端仍会显示审批提醒。

[2] 优化了同源写入前重复确认线路的问题。短时间内的连续操作可以复用已通过的检测结果，切换网络后会重新确认线路。

[3] 优化了 WebRTC 直连传输大文件的问题。上传和下载分块进行，发送队列拥堵时暂停，腾出空间后继续；取消单个文件时，聊天连接仍可使用。

[4] 优化了手机切回前台时连接被中断的问题。等待重试的会话可以在原页面继续连接，重连提示会在 DSH 会话就绪后消失。

[5] 优化了打开普通文件时缺少反馈的问题。点击后立即显示下载进度，可以单独取消；浏览器拦截弹窗时，预览留在聊天页内。

[6] 优化了启动与首次连接的体验问题。回访或启用「减少动态效果」时，工作区就绪后会立即收起启动画面。中英文入门说明从「连接同一 Wi-Fi、扫码、在电脑上确认」开始。

[7] 优化了连接诊断信息的问题。复制的摘要分别记录页面入口和当前会话线路，不包含地址、凭据或设备标识。

## 修复

[1] 修复了手机时钟与服务端不一致时，有效配对请求被提前判为过期的问题。

[2] 修复了自托管中继首次读取配置遇到短暂断网后需要重新扫码的问题。现在可以在原页面重试。

[3] 修复了自托管中继配对页误判有效主机公钥的问题，并为网络中断、二维码失效和配对被拒绝提供了不同提示。

[4] 修复了自托管中继的设备授权失效后，手机仍一直提示重连的问题。现在会引导用户重新扫码。

[5] 修复了浏览器拦截弹窗时，连续打开文件会累积预览和下载数据的问题。聊天页只保留最近打开的一份预览。

## 升级

```powershell
dsh plugin --profile <你的 profile> add @winlin926/dsh-carry@0.7.1
```

也可以在 DSH 插件页更新，更新后重启宿主。使用自托管公网节点的用户请同时升级 `remote-server`，以应用中继配对页和服务端的修复。
