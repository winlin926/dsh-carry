# v0.7.2

适配 DSH 0.2.3-alpha.1 / 0.2.3-alpha.2（兼容 0.2.2），修复了自托管中继大消息传输断连、配对通知丢失与公网节点切换残留等问题，并完善了手机端面板体验与中英文双语支持。

## 新增

- 新增了客户端面板完整的英文文案支持，主连接卡片、公网节点、设备管理、连接设置与插件更新均可随 DSH 界面语言动态切换。

## 优化与变更

- 优化了手机端面板展示：远端会话不再接收配对二维码与链接；手机端隐藏扫码区、多网卡地址、公网节点管理及开机自启开关，改为只读连接摘要卡。
- 优化了自托管节点设置体验：设置摘要直接显示当前节点地址，不再误报"域名未配置"；未配置固定网关域名时将网关相关设置收纳至折叠区。
- 优化了远端管理权限：禁止通过手机等非本机会话调用添加、检测、切换或删除公网节点等仅限本机的操作。
- 优化了宿主版本兼容：适配 DSH `0.2.3-alpha.1` 与 `0.2.3-alpha.2` 的连接认证与路由准入接口，并统一顶层 `engines.dsh` 与 `dsh.engines.dsh` 范围，在保留 DSH `0.2.2` 兼容的同时覆盖 `0.2.3` 系列与插件市场校验。
- 优化了内部架构与工程质量（无外部行为变化）：模块拆分、CI 接入 Biome 校验与 Docker 冒烟测试。

## 修复

- 修复了经由自托管中继传输超长 WebSocket 大消息时直接断连的问题，现会在两端自动分片传输并安全重组。
- 修复了自托管中继配对双方先后批准时可能漏发或重复发送完成通知的问题，确保精确投递一次。
- 修复了首次使用自托管节点或公网入口尚未可达时本机面板不显示公网节点管理区的问题。
- 修复了侧边栏配对审批弹窗未处理自托管节点配对请求的问题，现可在侧边栏直接审批或拒绝。
- 修复了存在待确认中继配对时刷新二维码未暂停的问题。
- 修复了设置面板「在浏览器打开」按钮使用裸地址而非带令牌完整链接的问题。
- 修复了保存固定域名时隐式切换至公网模式的问题，现仅保存域名配置。
- 修复了切换至自托管节点时残留旧网关公网域名，以及仍误检查网关域名或证书的问题。
- 修复了删除当前使用的网关节点时未停止公网连接并清理域名的问题。
- 修复了切换回局域网模式或停用连接时未清理 `lanTls` 状态的问题。
- 修复了 `remote-server` Docker 构建遗漏 `src/remote/node-api.ts` 导致镜像编译失败的问题。

## 升级与兼容性

```powershell
dsh plugin --profile <profile> add @winlin926/dsh-carry@0.7.2
```

- **宿主版本**：要求 DSH `>=0.2.2-rc.1 <0.3.0-0`（已兼容 `0.2.2`、`0.2.3-alpha.1` 与 `0.2.3-alpha.2`）。
- 也可直接在 DSH 插件页更新，更新后需重启 DSH 宿主；已配对手机、公网节点记录与既有设置继续保留，无需重新扫码。
- **自托管节点用户**：请同步升级并重启 `remote-server`，以获得大消息分片重组与配对通知精确投递修复。
